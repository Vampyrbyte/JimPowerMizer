## JimPowerMizer v1.0.0

One download for every client: **WoW Forever** (1.60.1), **Midnight** (Standard, 12.1.5), **Classic
Era** (1.15.9, also Season of Discovery and Hardcore), **TBC Anniversary** (2.5.6) and **Mists of
Pandaria Classic** (5.5.4). Coming from v0.1.5 or a 0.2.0 beta, your settings, profiles and savings
stats are kept.

### New: Midnight and Classic support
- **Loading:** two TOCs. `JimPowerMizer_Mainline.toc` lists interfaces 16001 and 120105 (Forever and
  Midnight), `JimPowerMizer_Classic.toc` lists 11509, 20506 and 50504 (the three Classic clients).
  Differences between the games live in one compatibility layer, chosen by interface number.
- **Graphics:** each client gets the settings its own Graphics menu has (see the profile editor below).
  Settings a client doesn't have are skipped, so the built-in profiles work everywhere.
- **Fishing:** on Forever and the Classic clients, the situation is a fishing pole in your main hand. On
  Midnight the pole sits in a profession slot, so it follows the Fishing channel (`UnitChannelInfo`,
  spell 131476; other Fishing spells match by name) and stays active for a grace period after it ends
  (10 s by default, set in the Fishing options), so looting and recasting don't switch back and forth;
  moving ends it early.
- **Midnight:** unit data the game hides in combat (secret values) is treated as unknown rather than
  compared. Placing crafting orders counts as a service window, and filling orders at a crafting table
  counts as the profession window. "Hide names and nameplates" covers `nameplateShowFriendlyPlayers`.
- **Classic:** options open with `/jpm` and from *Settings > AddOns*; there's no minimap addon menu on
  these clients. Flight paths are picked up by the 2-second check when the client doesn't report the
  take-off at once.

### New: instances are a lockout
- **Dungeon**, **Raid** and **Battleground** situations (arenas count as battlegrounds), plus **Delve**
  on Midnight. On by default with "your settings" at priority 93, above Idle, Flight path and Long idle,
  so nothing switches inside an instance, not even while you're idle or AFK, and no settings change can
  cause a hitch at a bad moment. Give one a graphics profile of its own if you'd rather.
- Scenarios aren't included, so story scenarios still go idle. A delve is a scenario with difficulty
  208. `/jpm debug` prints the instance type (and a scenario's difficulty) on each change.

### New: every Graphics menu setting in profiles
- The profile editor offers the same settings as the game's own Graphics menu on each client, in its
  order and with its level names (e.g. Shadow quality: Low, Fair, Medium, High, Ultra, Ultra High). It
  was built from Blizzard's menu code for each client, and follows the same rules for what to show:
  PBR liquid, outline mode and secondary lighting only where the client supports them; sun shafts only
  on Classic; no view distance on Classic. View distance, environment detail and ground clutter show
  1-10 like the game.
- New in profiles: sun shafts, projected textures, texture resolution, depth effects, outline mode,
  image-based anti-aliasing (`ffxAntiAliasingMode`; CMAA levels only where your card supports them),
  **multisample** (`MSAAQuality`, with the levels your card offers) and multisample alpha test, texture
  filtering, resample quality, vertical sync, and the FPS and render scale settings under the game's own
  names.
- **Ray traced shadows and variable rate shading** are listed but never put in a profile for you (not by
  a built-in profile, "Capture current" or a new profile): changing them crashed a Classic client, and
  Blizzard has them turned off on Forever and Midnight. Tick them yourself if your game menu offers them.

### New: reset and restore the built-in profiles
- **Reset to defaults** on Max saver, Light saver and Cinematic puts that one profile back to its
  default settings, after a confirmation. Your other profiles, situations and options don't change, and
  if the profile is in use the defaults apply at once. Greyed out while the profile already has them.
- **Restore a built-in profile:** deleted one? The Graphics profiles page lists the deleted built-ins;
  pick one to bring it back with its defaults. Situations that used it when it was deleted use it
  again, unless you've given them another profile since.

### Changes
- **Max saver** also turns off sun shafts, projected textures, depth effects, outline mode, both kinds
  of anti-aliasing and the multisample alpha test, and uses bilinear texture filtering and resampling.
  Light saver also turns off sun shafts. Existing profiles get these once, and only where you haven't
  set a value yourself. Texture resolution is never changed by a built-in profile (switching it reloads
  textures).

### Fixes
- **Console tweaks and quick switches:** when a saver started and ended less than half a second apart
  (e.g. a macro with `/jpm force idle` and `/jpm force off`), a setting the game changes a moment after
  another (`farclip` following View distance) could be put back wrong and a `/console` value lost.
  Such switches are now checked as one, against the values from before the first of them.
- **Multisample** is written as a plain number, as the game's menu does, and a value the client reports
  as "samples,coverage" counts as the same setting, so it's never mistaken for a change you made.

### Known limits
- Not yet tried in game: raid, battleground and arena lockouts (the dungeon one is checked), the delve
  lockout (the detection comes from Blizzard's API documentation), crafting orders, and crafting on the
  Classic clients. On Classic Era and TBC Anniversary, Enchanting opens its own window, which isn't
  watched yet: closing it doesn't end Crafting's grace period early (moving still does).
