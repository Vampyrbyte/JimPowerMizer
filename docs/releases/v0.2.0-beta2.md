## JimPowerMizer v0.2.0-beta2 (beta)

Beta of 0.2.0, which adds support for Midnight (Standard, 12.1.5). One download for both Forever
(1.60.1) and Midnight. New since beta1: energy savings, the same as in stable v0.1.5.

### New: energy savings
JimPowerMizer now records how long each graphics profile is applied and, from power figures you enter,
works out how much energy that saved. The game can't measure power, so the figures come from you.

- **Setup:** `/jpm` → **Savings** tab. Enter your PC's power draw in watts with your own graphics
  settings, and with each graphics profile applied. A plug-in power meter at the wall gives the best
  figures. Graphics card software (e.g. HWiNFO, `nvidia-smi`) only measures the card, so use the same
  method for every figure, with the game in the foreground.
- **How it's worked out:** energy saved = time applied × (watts at your settings − watts with the
  profile). Watts entered later count for time already recorded.
- **Optional:** a price per kWh with a currency symbol, and grams of CO2 per kWh. Each part only appears
  once its figure is entered.
- **`/jpm stats`:** time, energy, cost and CO2 per profile, plus lifetime and this-session totals.
  `/jpm stats reset yes` clears the stats and keeps your figures.
- **In chat:** with "Chat message when switching" on, the message when a profile ends adds what it
  saved, for profiles with watts entered.
- **Storage:** account-wide, keyed by profile name. Renaming keeps a profile's stats; deleting moves them
  to a "Deleted profiles" total, and a new profile with the same name starts from zero.
- **Known limit:** there's no window-focus API, so time with the game in the background counts the same
  as in the foreground; while the background frame rate cap (`maxFPSBk`) is in force, the savings shown
  may be too high.

### Midnight support (since beta1)
- **Loading:** the TOC lists interfaces 16001 and 120105, so the same package loads on both clients.
- **Fishing:** Midnight keeps the pole in a profession slot, so the situation follows the Fishing channel
  (`UnitChannelInfo`, spell 131476; other Fishing spells match by name). It stays active for a grace
  period after the channel ends (10 s by default, set in the Fishing options), so looting and recasting
  don't switch back and forth; moving ends it early. Forever keeps the pole-in-main-hand rule.
- **Crafting orders:** placing an order counts as a service window, and filling orders at a crafting
  table counts as the profession window (so closing it ends Crafting's grace period).
- **Secret values:** unit data Midnight hides in combat is treated as unknown rather than compared.
- **Hide names and nameplates** covers `nameplateShowFriendlyPlayers` (Midnight has no
  `nameplateShowFriends`).
- **Fix:** settings the game changes together (e.g. the minion names CVar also setting the pet, guardian
  and totem name CVars) are restored properly when a profile ends.

### Feedback wanted
- **Crafting orders windows:** the event names come from Blizzard's API documentation and haven't been
  seen in game yet.
- **Dungeons and raids** on Midnight, where more unit data is secret.
- Ray tracing and variable rate shading aren't handled yet: ray tracing is currently disabled by
  Blizzard, and VRS couldn't be tested.
